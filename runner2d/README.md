# Pulse Run (가제) — 음악에 맞춰 설계한 2D 횡스크롤 코스

구슬이 음악 박자에 맞춰 자동으로 달리고, 플레이어는 버튼 하나로 장애물을 넘는다.
- **누르면 점프** (평지 점프 = 정확히 1박자)
- **공중에서 한 번 더 누르면 대시**: 반 박자 동안 떨어지지 않고 수평으로 날며 실제로 1.5칸 앞서 나간다. 그 뒤 원래 자리로 서서히 돌아와 음악과 코스가 어긋나지 않는다. 대시벽(빛나는 유리벽)은 대시로만 깰 수 있다.
- **대시 예약**: 대시할 수 없는 순간(대시 중, 고리에 닿기 직전)에 누른 입력을 약 150ms 기억했다가, 가능해지는 순간 바로 대시한다. 고리에서 "탁탁" 이어 누를 수 있다.
- **벽은 닿는 순간 깨진다**: 대시로(또는 대시가 끝난 직후 약 80ms 안에) 닿은 벽은 붙어 있는 칸까지 통째로 사라진다. 대시가 벽 안에서 끝나도 죽지 않는다.
- **체크포인트**: 죽으면 마지막 체크포인트 한 박자 앞에서, 음악도 그 위치부터 다시 시작.
- 어렵게, 대신 죽으면 바로 재도전.
- **모드 관문**: 화면 높이의 거대한 대시벽. 깨고 지나가면 모드가 바뀐다.
- **바운스 모드**: 구슬이 박자마다 저절로 튄다(평지에서는 4칸마다 착지). 입력은 공중 대시뿐. 착지할 자리에 가시·구덩이가 있거나 정점에 벽이 있으면 대시로 해결한다. 박자에 안 맞게 착지하면 다음 박자까지 굴러가다 다시 튄다.

## 파일
- `logic.js` — 물리·충돌·코스 데이터·자동 풀이. 화면/오디오와 분리, 결정적(박자당 96스텝).
- `index.html` — 화면(Canvas 2D), 임시 음악(Web Audio 합성), 입력, HUD.

## 코스 만들기
`logic.js`의 `CHUNKS`에 한 마디(16칸 = 4박자)짜리 조각을 글자로 그리고, `COURSE.bars`에 마디 순서대로 이름을 나열한다.
```
#  블록      ^  바닥 가시     v  천장 가시(지금 코스에서는 안 씀)     D  대시벽     C  체크포인트     G  결승선
B  바운스 모드 관문     R  달리기 모드 관문   (그 칸에 화면 높이의 대시벽이 선다)
o  고정 톱날     S  움직이는 톱날(짝수 박자에 아래)     s  움직이는 톱날(홀수 박자에 아래)
J  점프대(밟으면 저절로 1.5박자·약 5칸 높이로 솟음)     O  대시 충전 고리(지나가면 공중에서 대시가 다시 참)
```
- 박자당 4칸. 구슬은 b번째 박자에 4b번째 칸에 있다. 박자에 맞춰 뛰면 2칸 뒤가 정점, 4칸 뒤가 착지.
- 체크포인트 앞 4칸은 평지로 둔다(그 자리에서 다시 시작).
- 바운스 구간: 구슬은 0·4·8·12번 칸에 착지한다. 대시하면 약 3.5칸 더 가서 떨어지고 다음 박자까지 굴러가므로, 대시 장애물 뒤 1.5박자는 비워 둔다.
- 대시는 "언제 누르느냐"만 묻는다. 대시 높이를 정밀하게 맞춰야 하는 구간(낮게 대시하는 터널 등)은 불쾌한 어려움이라 만들지 않는다.
- 움직이는 톱날은 2박자 주기로 2.2칸을 오르내린다. 구슬이 그 칸에 도착하는 박자가 정해져 있으므로(4칸 = 1박자), 4의 배수 칸에 두면 도착할 때 맨 아래(뛰어넘기) 또는 맨 위(뛰지 말고 달리기)에 있다.
- 천장 가시를 바닥에서 2칸 위에 깔면 "뛰면 안 되는" 구간이 된다.
- 고친 뒤 `node runner2d/tests/logic.test.js`로 깰 수 있는지 확인한다. 입력 하나의 타이밍 여유가 80ms 밑으로 내려가면 테스트가 실패한다.

## 개발자 모드
타이틀·일시정지·완주 화면 아래의 **개발자 모드** 버튼으로 켠다(브라우저에 저장됨). 켜면 `처음 / CP1~CP4` 버튼이 나와 그 체크포인트 한 박자 앞에서 바로 시작한다. 키보드 숫자 `0`(처음), `1`~`4`(체크포인트)도 된다. 건너뛰어 시작한 판은 최고 기록에 넣지 않는다.

## 테스트
```bash
node runner2d/tests/logic.test.js   # 자동 풀이: 처음/각 체크포인트부터 완주 가능, 대시 필수 구간, 마디별 타이밍 여유(ms)
node runner2d/tests/windows.js      # 입력마다의 타이밍 여유 표 (앞 입력을 모두 여유 한가운데에서 눌렀다고 치고 잰 값)
node runner2d/tests/e2e.js          # 헤드리스 Chromium: 실제 화면 누르기, 죽음·재도전, 체크포인트, 완주, 세로/가로 화면
```
