# RythmnEscape

턴제 탈출 게임. 병아리가 **점프로 한 칸씩** 이동하며, 적들을 피해 출구까지 탈출합니다.

## 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| 방향키 / WASD / 스와이프 | 한 칸 점프 |
| Space / 탭 / 대기 버튼 | 제자리 대기 (턴 넘기기) |
| Z | 되돌리기 |
| R | 다시하기 |

## 규칙 (프로토타입)
- 플레이어가 1번 움직이면 → 모든 적이 1번 움직임
- 적이 **다음 턴에 갈 칸은 점선으로 미리 표시**됨 → 그 칸에 서 있으면 잡힘
- 적이 있는 칸으로 점프해도 실패
- 출구(초록)에 닿으면 클리어

### 적
- **순찰병 (빨강)**: 한 방향으로 가다 막히면 뒤돌아섬
- **추적자 (보라)**: 최단 경로로 플레이어를 쫓아옴 (예고된 칸으로 한 박자 늦게)

### 타일
- **무너지는 발판 (갈색)**: 밟고 떠나면 구멍이 됨. 적은 구멍을 못 건넘

## 구조
- `index.html` — 단일 파일. `<script id="logic">`(순수 게임 로직 + 레벨 검증용 `solve()`)과 렌더링/입력 스크립트로 분리
- 캐릭터 디자인: `kong` 저장소의 유치원 병아리(chick-base) 스타일 참고
