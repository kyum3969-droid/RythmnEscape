# RythmnEscape

리듬 턴제 탈출 게임. 병아리가 **비트에 맞춰 점프로 한 칸씩** 이동하며, 적들을 피해 출구까지 탈출합니다.

## 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| 방향키 / WASD / 스와이프 | 한 칸 점프 |
| Space / 탭 / 대기 버튼 | 제자리 대기 (턴 넘기기) |
| R | 다시하기 |
| Z | 되돌리기 (퍼즐 모드만) |

## 모드
- **🎵 리듬 모드 (기본)** — 한 박자 = 한 턴. 3·2·1 카운트다운 뒤 시작
  - 박자 ±60ms 안에 입력: **PERFECT**, ±130ms 안에 입력: **GOOD**
  - 박자를 그냥 흘려보냄: **MISS**. 제자리에 멈추고 적은 그대로 움직임
  - 박자보다 너무 일찍 누름: **MISS**. 그 박자에는 움직일 수 없음 (연타 방지)
  - 클리어하면 PERFECT/GOOD/MISS 수와 최대 콤보로 랭크(S/A/B/C)를 매김
  - 음악은 Web Audio로 직접 합성 (음원 파일 없음). 스테이지마다 BPM이 다름 (84~104)
- **🧩 퍼즐 모드** — 시간 제한 없는 턴제. 되돌리기 가능

## 규칙 (프로토타입)
- 플레이어가 1번 움직이면 → 모든 적이 1번 움직임
- 적이 **다음 턴에 갈 칸은 점선으로 미리 표시**됨 → 그 칸에 서 있으면 잡힘
- 적이 있는 칸으로 점프해도 실패
- 출구(초록)에 닿으면 클리어

### 적
- **순찰병 (빨강)**: 한 방향으로 가다 막히면 뒤돌아섬
- **추적자 (보라)**: 최단 경로로 플레이어를 쫓아옴 (예고된 칸으로 한 박자 늦게)

### 타일
- **무너지는 발판 (갈색)**: 밟고 떠나면 구멍이 됨. 적은 구멍을 못 건넘

## 구조
- `index.html` — 단일 파일. `<script id="logic">`(순수 게임 로직 + 레벨 검증용 `solve()`)과 렌더링/입력 스크립트로 분리
- 캐릭터 디자인: `kong` 저장소의 유치원 병아리(chick-base) 스타일 참고
