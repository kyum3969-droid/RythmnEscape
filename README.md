# Pulse Bounce (가제)

음악에 맞춰 저절로 튀는 공을 버튼 두 개로 다루는 모바일 리듬 게임. 광고 수익을 목표로 한다.

- 공은 박자마다 저절로 튀고, 한 박에 네 칸씩 앞으로 간다(공의 자리는 시간에 묶여 있다).
- **왼쪽 누르고 있기 = 멈춤**(그 높이에 떠 있는다, 한 번 튈 때 한 박까지), **오른쪽 누르기 = 점프**(공중에서는 이단 점프).
- 코스는 곡마다 "키 패턴"을 먼저 정하고, 그 패턴으로만 지나갈 수 있게 장애물을 만들어 낸다. 같은 것을 두 번 보여 주고 세 번째에 비튼다(함정).
- 지금은 웹(HTML 한 장)에서 다듬는 중이다. 방향이 정해지면 Godot으로 옮긴다.

## 실행
`bounce2d/index.html`을 브라우저로 연다(빌드 없음). 곡 파일을 읽으려면 로컬 서버로 여는 것이 좋다:

```
cd bounce2d && python3 -m http.server 8000
```

## 테스트
```
cd bounce2d
node tests/logic.test.js   # 규칙·패턴·코스(모든 라운드를 패턴대로 완주, 함정, 밀도)
node tests/e2e.js          # 실제 화면(Playwright)
```

## 라운드
1~19라운드. 라운드마다 곡과 주제가 다르다(예: 10라운드 공장의 망치와 분쇄 롤러, 11라운드 속임수, 12라운드 쇠 봉우리, 14라운드 정글 신전의 흔들리는 돌추, 15라운드 궤도 고리, 16라운드 불기둥, 17라운드 해파리, 18라운드 깜빡이는 등롱, 19라운드 용암 덩이). 피버 연출도 라운드마다 다르다. 자세한 것은 [bounce2d/README.md](bounce2d/README.md).

이 저장소에 있던 이전 프로토타입들(턴제 탈출 `index.html`·`web3d/`·`godot/`, 누르면 점프하는 `runner2d/`)은 지웠다. git 기록에는 남아 있다.
