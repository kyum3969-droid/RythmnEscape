# Pulse Bounce (가제) — 저절로 튀는 공, 멈춤과 점프

`runner2d`(누르면 점프)와 비교해 보려는 두 번째 프로토타입. 기본 동작 자체가 바운스다.

- 공은 **박자마다 저절로 튄다** (평지에서는 4칸마다 착지). 박자와 어긋나게 착지하면 다음 박자까지 굴러가다 다시 튄다.
- **왼쪽 누르고 있기 = 멈춤**: 공중에서 그 높이에 멈춘다. 세상(코스·음악)은 계속 흐르므로 장애물이 밑으로 지나간다. 한 번 튈 때마다 최대 1박자, 나눠 쓸 수 있고 다시 튀면 가득 찬다. 멈춘 동안 음악이 먹먹해진다.
- **오른쪽 누르기 = 점프**: 땅에 있으면(박자와 어긋나게 착지해 굴러가는 중) 그 자리에서 점프, 공중이면 **이단 점프**(한 번 튈 때마다 한 번, 높이는 일반 점프와 같아 꼭대기에서 쓰면 4.5칸). 착지 직전에 눌러 두면 착지하자마자 뛴다. 고리를 지나면 이단 점프가 다시 찬다.
- 멈춤은 공중에서만 듣는다. PC: `←`/`A`/`Shift` 누르고 있기 = 멈춤, `→`/`↑`/`D`/`W`/`Space` = 점프.
- 체크포인트, 개발자 모드(체크포인트 이동), 화면 스타일은 `runner2d`와 같다.

## 속도
타이틀·일시정지 화면의 **속도** 버튼: 느림(80 BPM) / 보통(96, 기본) / 빠름(112) / 아주 빠름(128). 물리는 박자 단위라 코스는 그대로이고 템포만 바뀐다(공·스크롤·음악이 함께). 처음 버전은 128이었고 한 번 튀는 데 0.47초라 예측하기 어려웠다. 보통은 0.63초.

## 해 보고 뺀 것
- 대시(수평으로 날며 앞서 나가기)와 대시벽: 벽 자체가 별로였고, 중간지점에 떨어지면 손쓸 수 없는 문제를 "땅에서 누르면 점프"로 풀면서 오른쪽 버튼을 점프로 바꿨다.
- 일정 속도로 오르내리기, 누르면 가까운 높이 줄에 붙이기: 조작감이 나빠져서 되돌림.
- 착지 칸 위에 뜬 톱날로 "멈추지 말라"고 하는 함정: 그냥 튀어도 내려오는 톱날에 걸려, 50ms짜리 멈춤을 넣어야만 통과됐다.

## 파일
- `logic.js` — 물리·충돌·코스·자동 풀이(`solve`는 [아무것도 안 함 / 멈춤 / 점프]를 탐색, `noFreeze`·`noJump`·`noGroundJump` 옵션으로 입력을 막아 볼 수 있음)
- `index.html` — 화면, 임시 음악, 입력(화면 왼쪽 절반 / 오른쪽 절반)

## 코스 글자
```
#  블록(한 칸 턱은 저절로 올라탐)    ^  가시    X  가시 기둥(세로 함정)    O  점프 충전 고리    J  점프대    S / s  움직이는 톱날    C  체크포인트    G  결승선
```
공은 0·4·8·12번 칸에 착지한다. 설계 규칙:
- 착지 칸에 위험(가시·구덩이·오르내리는 톱날)이 있으면 그 칸을 건너뛰어야 한다. 멈춤(최대 4칸)이나 이단 점프(꼭대기에서 쓰면 약 2.8칸 더) 하나로 한 칸, 둘을 이으면 두 칸.
- 박자와 어긋나게 착지하면 다음 박자 칸까지 굴러간다. 굴러가는 동안에도 점프를 누르면 바로 뛰므로, 그 앞에 가시가 있어도 손쓸 수 있다. 단, 박자에서 1/8박 안쪽으로 늦은 착지는 바로 튀되 그만큼 낮게 튀어 다음 박자에 맞춘다.
- 착지 칸 사이의 가시는 그냥 튀면 넘어간다(쉬어 가는 마디).
- **가시 기둥(X)**: 2칸 높이는 발 높이 2칸 이상에서 멈춰서 넘는다. 튀어 오른 지 2칸째(6번 칸)에 두면 멈춤을 누를 시간이 약 220ms. 맨 윗줄에 두면 천장까지 이어져 "위아래 기둥 사이의 틈"이 된다. 3칸 높이는 이단 점프나 점프대로 넘는다.
- **계단**: 한 칸(1.05칸 이하) 턱은 옆에서 부딪혀도 저절로 올라탄다. 착지 칸마다 한 칸씩 올리면 공이 알아서 오른다. 2칸 이상은 부딪히면 죽는다.
- 조각을 고치면 `node bounce2d/tests/windows.js`로 입력마다의 여유(ms)를 확인한다. 테스트는 96 BPM에서 140ms 미만이면 실패한다.

## 화면 표시
- 착지 자리 표시는 평소엔 옅고, **지금 이 점프로 닿을 자리 하나만** 밝게(바닥 선 + 세로 선) 표시한다. 멈춘 동안에는 "지금 손을 떼면 닿을 자리"를 보여 주며, 그대로 떨어지면 죽는 경우에는 표시하지 않는다.
- 멈춤은 테두리가 아니라 **공 색**으로 보인다: 멈추면 공 색이 바뀌고, 남은 멈춤 시간만큼 아래부터 밝게 차 있다.

## 테스트
```bash
node bounce2d/tests/logic.test.js   # 멈춤/대시 동작, 완주 가능(처음·각 체크포인트), 멈춤·대시 각각 필수, 조각별 타이밍 여유
node bounce2d/tests/windows.js [BPM] # 조각별로 꼭 필요한 입력과 그 여유(ms) 표
node bounce2d/tests/e2e.js          # 헤드리스 Chromium: 왼쪽 누르고 있기·오른쪽 누르기(실제 포인터), 키보드, 완주, 개발자 모드, 세로/가로
```
